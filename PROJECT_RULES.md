# PROJECT RULES

Every decision should answer one question:

Will this help us acquire more high-quality clients?

---

Do not add unnecessary features.

Do not add unnecessary animations.

Do not overcomplicate the website.

---

The website exists to:

Build trust

Generate leads

Book strategy calls

Sell AI engagements

---

Every page should have:

One purpose

One primary CTA

One secondary CTA

---

Always prioritize:

Business value

Speed

SEO

Conversions

Mobile usability

Accessibility

---

Design philosophy:

Simple

Premium

Modern

Executive

Minimal

High trust
