## Industry Pages

Each industry page must target its actual industry/business-system problems.

Do not create substantially identical metadata with only the industry name changed.

## Future Resources

Before creating a resource, document:

- working title
- target question
- primary search intent
- primary commercial destination
- related resources
- CTA
- canonical route

Avoid resource cannibalization.
