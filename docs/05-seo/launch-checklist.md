# Your AI Department — SEO Launch Checklist

Status: V1

## Indexability

Verify:

- production pages are indexable
- staging/testing URLs are not unintentionally indexed
- robots.txt is correct
- XML sitemap is generated and reachable
- canonical tags are correct

## Metadata

Verify every public page has:

- unique title
- unique meta description
- canonical
- Open Graph metadata
- social metadata
- one logical H1

## Technical

Verify:

- HTTPS
- correct redirects
- no broken internal links
- no unnecessary redirect chains
- no 404s from navigation/footer
- mobile usability
- performance
- image dimensions
- accessible alt text where appropriate

## Structured Data

Validate implemented structured data.

Do not ship invalid or misleading markup.

## Search Console

After launch:

- verify domain property
- submit sitemap
- monitor indexing
- review crawl/indexing issues
- review search queries
- review page performance

## Content

Before publishing supporting resources:

- confirm search intent
- confirm canonical commercial destination
- check cannibalization
- review claims
- review internal links
- review CTA
- review metadata

## Analytics

Analytics and conversion measurement should be implemented in a later approved production sprint.

Do not allow analytics implementation to silently change cookie/privacy obligations.

## Paid Advertising

Before sending Google Ads or Meta Ads traffic:

- verify landing page
- verify conversion action
- verify lead delivery
- verify contact form
- verify phone/booking path where applicable
- verify attribution
- verify privacy disclosures

Do not spend paid-media budget on an unverified conversion path.
