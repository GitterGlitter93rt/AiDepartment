# 2. ONE CORE ENGINE, DIFFERENT BUSINESS CONTEXT

Every vertical uses the same core pipeline:

`Territory`
-> `search/ad discovery`
-> `identity`
-> `website/business research`
-> `Evidence Ledger`
-> `Module 4C score`
-> `research completeness`
-> `opportunity hypotheses`
-> `current offer mapping`
-> `Call Pack`
-> `Human Assist / approved contact workflow`
-> `outcome / learning`.

The profile changes:

- searches;
- exclusions;
- business journey;
- public qualification signals;
- likely leaks;
- questions;
- decision-maker priority;
- professional boundaries;
- ROI tool selection;
- hook ranking.

The profile does NOT change the canonical Module 4C scoring formula.

# 4. WHICH VERTICALS SHOULD START WITH GOOGLE ADVERTISERS?

## Extremely strong Google-first candidates

- HVAC
- Plumbing
- Roofing
- Collision Repair
- Law Firms

Reason: high-intent search frequently maps directly to a near-term service/problem and the advertiser has already demonstrated willingness to purchase demand.

## Google + event/context candidate

- PDR/Hail

Reason: current hail-market timing matters as much as generic business presence. Google plus Meta/current-market evidence is particularly valuable.

## Mixed-channel candidate

- Real Estate

Google can still help, but Meta, portals, seller funnels, listings, open houses, team size, and database/nurture sophistication may be equally or more relevant depending on campaign.

This hierarchy is an operating hypothesis to test, not a permanent conclusion.

# 8. CROSS-VERTICAL CALL-PACK RULE

Every Call Pack should answer these seven questions:

1. What did we actually observe?
2. Which vertical/business context applies to this campaign?
3. What is the highest-value hypothesis worth testing?
4. What should the first question be?
5. Which role likely owns the problem?
6. What are we forbidden to claim?
7. What is the best next step if the hypothesis is confirmed?

It should not attempt to dump the entire profile into the live conversation.

---

# 9. CROSS-VERTICAL NO-SALE RULE

A prospect leaving the vertical target list does not mean the system failed.

Correct outcomes include:

- strong process, no meaningful YAD problem;
- economics too weak;
- current software already solves the problem;
- required integration infeasible;
- unsafe/professionally inappropriate automation requested;
- company is simply not ready;
- wrong role or wrong business classification.

The brain must protect long-term credibility by allowing these outcomes.

# CORE RULE

The Market Miner does not sell industries a generic “AI solution.”

It detects the business model, observes real public demand/workflow signals, selects the correct industry context, asks a business question grounded in that context, and allows the prospect's actual process to determine what — if anything — YAD should recommend.
