# AI for Screen Enclosure Lead Qualification and Site-Visit Scheduling

## Suggested Route

/resources/ai-for-screen-enclosure-lead-qualification-and-scheduling/

## Core Thesis

Not every incoming inquiry needs the same next step.

AI-assisted intake can organize basic project information and coordinate site visits while estimators remain responsible for evaluating the actual property.

## Recommended Structure

### Capture Useful Information

Potential fields:

- contact information
- property location
- project type
- existing structure
- new enclosure vs. repair
- desired timeline
- consultation preference

### Route Appropriately

Lead
→ basic qualification
→ appropriate salesperson/estimator
→ site visit
→ reminder
→ estimate workflow

### Scheduling

Discuss:

- calendar availability
- confirmations
- reminders
- rescheduling
- internal notifications

### Human Judgment

AI should not determine:

- structural feasibility
- engineering requirements
- permit requirements
- final pricing
- site-specific scope
