# Automating Estimate Follow-Up for Outdoor Living Projects

## Suggested Route

## Core Thesis

Outdoor-living projects can involve long consideration cycles and multiple competing bids.

Automation should help sales teams maintain consistent follow-up without making a high-value project feel transactional.

## Recommended Structure

Potential projects:

- hardscapes
- patios
- pavers
- outdoor kitchens
- landscape renovations
- lighting
- drainage
- design-build projects

Workflow:

estimate
→ confirmation
→ scheduled follow-up
→ project information
→ human conversation
→ decision
→ nurture
