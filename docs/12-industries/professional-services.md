# EMPLOYEE CAPACITY

A professional-services firm often scales by hiring more professionals and support staff.

Before adding headcount, leadership may ask:

- Which work is repetitive?
- Which work can be accelerated?
- Which administrative steps can be automated?
- Which knowledge can be retrieved faster?
- Can existing employees handle additional client volume?

AI can become a leverage tool for the firm.
