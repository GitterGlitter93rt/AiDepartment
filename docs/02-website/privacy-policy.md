# INFORMATION USERS SHOULD NOT SUBMIT

Public website forms should instruct users not to submit information such as:

- Passwords
- Social Security numbers
- Full bank account information
- Payment-card information unless processed through an approved payment processor
- Protected health information unless an appropriate compliant system has been intentionally implemented
- Highly sensitive legal documents
- Confidential customer files
- Trade secrets inappropriate for a public form

# DATA SECURITY

Reasonable safeguards should be used to protect stored information.

Potential measures include:

- HTTPS
- Access controls
- Strong authentication
- Secure API credentials
- Limited permissions
- Server-side secret storage
- Software updates
- Backups
- Logging
- Spam protection

No website should claim that transmission or storage is completely secure.

# DATA SHARING

Do not state that data is never shared if third-party vendors process information.

Information may be disclosed to service providers that assist with operating the website or providing services.

Do not represent ordinary service-provider processing as selling data unless legally required to do so.

Final wording requires legal review.
