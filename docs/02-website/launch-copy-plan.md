# Copywriting Rules

The website should sound:

- Executive
- Practical
- Sophisticated
- Business-focused
- Clear
- Confident
- Modern

Avoid:

- Excessive AI hype
- Buzzword-heavy copy
- Claims that AI will replace entire teams without analysis
- Guaranteed ROI
- Generic agency language
- Overuse of the word revolutionary
- Technical explanations that do not connect to business value
