# URL Rules

- Use lowercase URLs.
- Separate words with hyphens.
- Keep URLs short and descriptive.
- Avoid unnecessary dates or category folders.
- Use one primary canonical URL per topic.
- Redirect outdated URLs rather than duplicating pages.
