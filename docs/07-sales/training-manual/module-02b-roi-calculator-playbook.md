# Module 2B - YAD ROI Calculator Playbook

Status: Active Working Draft

## Purpose

This module turns the business-economics doctrine into field-ready financial diagnosis tools. Salespeople should use the correct calculator for the business problem being diagnosed rather than forcing every prospect through one giant worksheet.

Each calculator must follow these rules:

- Use prospect/client data first when available.
- Clearly label estimates and planning assumptions.
- Separate theoretical exposure from realistically recoverable opportunity.
- Do not present scenarios as guarantees.
- Do not call recovered employee capacity payroll savings unless actual cost reduction is documented.
- Never frame a calculator around firing or replacing staff.
- If the inputs are too weak, stop and collect better data.

## Calculator selection

Choose the calculator based on the leak:

1. Missed Call ROI
2. Lead Response ROI
3. Unsold Estimate / Follow-Up ROI
4. Lead Reactivation ROI
5. No-Show ROI
6. Employee Capacity ROI
7. Sales Administration Capacity
8. Overtime Reduction
9. Reporting / Administrative Work
10. Document Processing
11. Advertising Efficiency
12. Hiring Deferral / Capacity Planning
13. Accounts Receivable Efficiency
14. Final Implementation ROI / Payback

# 1. Missed Call ROI Calculator

## Use when

- calls go unanswered
- after-hours calls reach voicemail
- overflow is inconsistent
- call response is a suspected sales bottleneck

## Inputs

- inbound calls per month
- unanswered percentage
- percentage of unanswered calls that are legitimate new-business opportunities
- realistic capture/close scenario
- average customer revenue
- optional gross margin / contribution information

## Formulas

Unanswered Calls = Monthly Calls x Unanswered %

Theoretical Exposure = Unanswered Calls x Average Customer Revenue

Qualified Missed Opportunities = Unanswered Calls x Legitimate Opportunity %

Scenario Customers = Qualified Missed Opportunities x Scenario Capture/Close %

Recoverable Revenue Scenario = Scenario Customers x Average Customer Revenue

Annual Scenario = Monthly Recoverable Revenue Scenario x 12

## Say

"This is the revenue represented by the problem using the assumptions we agreed on. It is not guaranteed recovered revenue."

## Do not say

"Our AI phone agent will recover all of this."

---

# 2. Lead Response ROI Calculator

## Use when

- web leads wait too long
- paid leads are not contacted quickly
- lead assignment is inconsistent
- first-touch follow-up is manual

## Inputs

- monthly inbound leads
- current conversion rate
- scenario conversion rate
- average customer revenue
- current response time
- desired response workflow

## Formulas

Current Customers = Monthly Leads x Current Conversion Rate

Scenario Customers = Monthly Leads x Scenario Conversion Rate

Additional Scenario Customers = Scenario Customers - Current Customers

Monthly Revenue Scenario = Additional Scenario Customers x Average Customer Revenue

Annual Revenue Scenario = Monthly Revenue Scenario x 12

## Rule

Never invent a conversion-rate improvement. Use client history, a measured pilot, a reliable benchmark with caveats, or a clearly labeled illustrative scenario.

---

# 3. Unsold Estimate / Follow-Up ROI Calculator

## Use when

- estimates/proposals receive weak follow-up
- follow-up depends on individual employees
- unsold estimates accumulate
- the business cannot report estimate-to-sale conversion

## Inputs

- estimates/proposals per month
- number or percentage unsold after initial presentation
- percentage considered legitimate recoverable opportunities
- scenario recovery/close rate
- average sold job / contract revenue

## Formulas

Unsold Estimates = Monthly Estimates x Unsold %

Theoretical Exposure = Unsold Estimates x Average Sold Value

Qualified Recoverable Estimates = Unsold Estimates x Legitimate Opportunity %

Scenario Recovered Customers = Qualified Recoverable Estimates x Scenario Recovery %

Recoverable Revenue Scenario = Scenario Recovered Customers x Average Sold Value

## Rule

Do not imply every unsold estimate was "lost" because of follow-up.

---

# 4. Lead Reactivation ROI Calculator

## Use when

- old leads sit untouched
- past estimates are not systematically contacted
- inactive customer databases exist
- marketing acquisition spend has already created a database asset

## Inputs

- inactive leads/contacts
- contactable percentage
- response-rate scenario
- qualification/appointment rate
- close rate
- average customer value

## Formula funnel

Inactive Database -> Contactable -> Responses -> Qualified/Appointments -> Customers -> Revenue Scenario

## Rule

Never multiply the entire database by customer value.

---

# 5. No-Show ROI Calculator

## Use when

- appointments no-show frequently
- reminders are weak
- rebooking is inconsistent
- schedule capacity is wasted

## Inputs

- appointments per month
- current no-show rate
- scenario no-show rate
- immediate appointment value
- optional downstream customer/treatment value

## Formulas

Current No-Shows = Appointments x Current No-Show %

Scenario No-Shows = Appointments x Scenario No-Show %

Recovered Appointment Scenario = Current No-Shows - Scenario No-Shows

Immediate Monthly Revenue Represented = Recovered Appointments x Immediate Appointment Value

## Rule

Use conservative immediate appointment value unless lifetime-value data is reliable.

---

# 6. Employee Capacity Calculator

## Use when

- repetitive administrative work is common
- teams are overloaded
- data is entered repeatedly
- employees spend excessive time searching, reporting, scheduling, or updating systems

## Inputs

- employees affected
- repetitive hours per employee per week
- loaded hourly labor cost
- addressable percentage
- productive weeks per year

Default planning value when appropriate: 48 productive weeks, clearly labeled.

## Formulas

Annual Repetitive Hours = Employees x Repetitive Hours/Week x Productive Weeks

Addressable Hours = Annual Repetitive Hours x Addressable %

Potential Annual Capacity Value = Addressable Hours x Loaded Hourly Labor Cost

## Preferred language

"Potential annual employee capacity value."

## Never say

"This lets you fire X employees."

---

# 7. Sales Administration Capacity Calculator

## Use when

Salespeople spend material time on:

- CRM entry
- meeting notes
- follow-up drafting
- proposals
- scheduling
- pipeline reporting

## Inputs

- number of salespeople
- administrative hours per salesperson per week
- loaded hourly cost
- addressable percentage
- productive weeks

## Output

- annual sales administration hours
- potentially recoverable selling hours
- potential capacity value

## Strategic question

"What could your sales team produce with those hours returned to selling and customer activity?"

---

# 8. Overtime Reduction Calculator

## Use when

- repetitive/admin workload directly contributes to overtime
- peak periods create recurring office overtime

## Inputs

- employees receiving overtime
- overtime hours per employee per week
- overtime hourly cost
- percentage of overtime specifically tied to addressable workflow
- scenario reduction percentage

## Rule

Do not assume all overtime is addressable.

---

# 9. Reporting / Administrative Work Calculator

## Use when

- reports are manually assembled
- managers repeatedly consolidate spreadsheets
- recurring administrative cycles consume staff time

## Inputs

- employees involved
- hours per reporting/admin cycle
- cycles per year
- loaded labor cost
- addressable percentage

## Output

- annual manual hours
- addressable hours
- potential capacity value

---

# 10. Document Processing Calculator

## Use for

- invoices
- receipts
- estimates
- claims
- applications
- contracts
- forms
- customer documents

## Inputs

- documents per month
- minutes per document
- loaded hourly labor cost
- processing-time reduction scenario

## Formulas

Current Monthly Hours = Documents x Minutes per Document / 60

Addressable Monthly Hours = Current Monthly Hours x Reduction %

Potential Annual Capacity Value = Addressable Monthly Hours x 12 x Loaded Hourly Labor Cost

---

# 11. Advertising Efficiency Calculator

## Use when

- paid media spend is meaningful
- attribution is weak
- lead quality is poor
- CPL/CAC is high
- campaign-to-revenue visibility is incomplete

## Inputs

- monthly spend
- qualified leads
- customers
- average customer revenue
- current cost per qualified lead
- current CAC
- scenario efficiency values

## Calculations

Cost Per Lead = Spend / Leads

Customer Acquisition Cost = Spend / Customers

Scenario Additional Leads at Same Spend = (Spend / Scenario CPL) - Current Leads

## Advertising audit rule

If using an inefficient-spend scenario, call it:

"Advertising spend potentially worth auditing."

Do not call it "waste" until supported by a real audit.

---

# 12. Hiring Deferral / Capacity Planning Calculator

## Use when

- growth is expected to require additional administrative/support hiring
- the existing team is overloaded because of repetitive workflows

## Inputs

- planned role compensation
- employer burden / loaded cost
- recruiting/onboarding cost
- workload driving the hire
- addressable percentage of that workload

## Rule

The business case is not "replace a future employee with AI."

The question is:

"Can better workflows allow the current team to handle additional volume before the business needs to add overhead?"

Any hiring deferral must be validated through workflow analysis.

---

# 13. Accounts Receivable Efficiency Calculator

## Use when

- employees manually chase unpaid invoices
- reminders/escalations are inconsistent
- reporting is weak

## Labor inputs

- employees involved
- hours per week
- loaded labor cost
- addressable percentage

## Working-capital inputs when available

- outstanding receivables
- current days sales outstanding
- potential reduced DSO scenario

## Rule

Faster collections are not new revenue. Describe the effect as potential working-capital improvement.

---

# 14. Final Implementation ROI / Payback Calculator

## Inputs

- conservative annual value
- expected annual value
- aggressive annual value
- implementation cost
- monthly/annual ongoing cost

## Formulas

First-Year Investment = Implementation Cost + First-Year Ongoing Cost

First-Year Net Value = Estimated Annual Value - First-Year Investment

Simple ROI % = First-Year Net Value / First-Year Investment x 100

Simple Payback = Investment / Estimated Monthly Value

## Presentation

Show Conservative / Expected / Aggressive scenarios when uncertainty is material.

Never present one scenario as guaranteed performance.

# Calculator conversation framework

For every calculator:

1. Identify the problem.
2. Ask for volume.
3. Ask for the value of one unit/customer/job/hour.
4. Establish the failure/leak rate.
5. Separate legitimate opportunities from theoretical exposure.
6. Agree on a conservative recovery or improvement assumption.
7. Calculate the business-value scenario.
8. Compare the scenario with the investment.
9. Document missing data.
10. Move to the appropriate next step.

# Field-data rule

If the prospect does not know a required number, write "Unknown - measure" rather than inventing an answer.

Missing data may itself identify a reporting/visibility opportunity.

# Required form outputs

Each printable/digital form should include:

- Prospect / company
- Date
- Salesperson
- Source of each key input (verified data / client estimate / benchmark / illustrative assumption)
- Raw inputs
- Calculations
- Theoretical exposure where relevant
- Conservative / expected / aggressive scenario fields where relevant
- Missing data / verification needed
- Notes
- Next step
- Explicit disclaimer that scenarios are estimates and not guaranteed outcomes

# Certification standard

A rep passes Module 2B when they can select the correct calculator, collect the required inputs, identify unreliable assumptions, calculate a conservative scenario, explain the result without exaggeration, and tell the prospect what additional data is needed before a stronger ROI claim can be made.
